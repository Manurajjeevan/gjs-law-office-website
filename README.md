# GJS Advocates & Solicitors — Website Demo

A cinematic, scroll-driven concept site for GJS Advocates & Solicitors. The office tour uses layered motion and camera-style movement over the supplied office photography, with transparent editorial panels and a warm charcoal, ivory, and brass palette.

## Preview locally

Open `index.html` in a modern browser. For best results, serve this folder with any static file server so the page and its assets load consistently.

## Project contents

- `index.html` and the CSS/JavaScript files: website layout, visual styling, and scroll-driven office tour.
- `assets/`: supplied GJS office photographs and animated GIFs used by the site.

This is a client presentation demo. Replace placeholder contact details and confirm all firm copy, practice descriptions, and imagery before production use.
